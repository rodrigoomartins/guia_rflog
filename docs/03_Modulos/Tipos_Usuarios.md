# Tipos de Usuario

## O que e

Esta secao descreve os diferentes perfis de usuarios do sistema RFLog, cada um com permissoes e acessos especificos. Os usuarios sao divididos em quatro perfis principais.

## Como Acessar

Informacao de referencia - nao corresponde a uma tela especifica do sistema, mas sim a documentacao sobre os tipos de usuario disponiveis.

## O que Voce Ve

A documentacao apresenta uma tabela com os quatro perfis de usuario e suas rispettivas permissoes:

| Perfil | Permissoes |
|---|---|
| **Administrador** | Acesso total. Pode deletar movimentacoes, inventarios e vendas. Pode criar outros usuarios, editar senhas e gerenciar todas as funcionalidades do sistema. |
| **Operador** | Realiza as operacoes basicas (inventarios, transferencias, vendas, impressao) mas **nao pode excluir** registros. Visualiza e cria, mas nao deleta. |
| **Vendedor** | Usuario de visualizacao. Consegue visualizar as vendas e pre-vendas feitas para seu usuario especifico. Perfil limitado a consulta das proprias vendas. |
| **Fornecedor** | Usuario restrito. So consegue **criar ordens de impressao** para que sejam impressas por outros usuarios. Consegue ver as ordens que criou e gerencia-las. Util para clientes que tem fornecedores que precisam imprimir suas etiquetas — os fornecedores acessam o RFLog com seu login e criam/gerenciam suas ordens de impressao. |

## Funcionalidade

Define os perfis de usuario e seus niveis de acesso no sistema RFLog. Essa classificacao determina quais funcionalidades cada tipo de usuario pode acessar e quais acoes podem realizar.

## Dicas

- Atribua o perfil de usuario adequado conforme as responsabilidades e necessidades de cada pessoa
- Lembre-se que apenas usuarios com perfil **Administrador** podem criar outros usuarios
- Revise periodicamente as permissoes atribuidas para garantir seguranca e adequacao conforme mudancas de cargo ou responsabilidades
