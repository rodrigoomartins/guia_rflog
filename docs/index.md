# Guia de Usuário RFLog

Bem-vindo ao **Guia de Usuário do RFLog**, o sistema de gestão e rastreabilidade de produtos via tecnologia RFID desenvolvido pela **Votu RFID Solutions**.

![Dashboard RFLog](assets/screenshots/02_dashboard.png)

## O que é o RFLog

O RFLog permite que empresas acompanhem o ciclo completo de seus produtos — desde a impressão da etiqueta RFID até a venda final — com controle de estoque, transferências, inventários e integração com ERPs.

## Principais Funcionalidades

### Impressão de Etiquetas
Crie e imprima etiquetas RFID para seus produtos. Saiba mais em [Impressão - Imprimir](03_Modulos/Impressao_Imprimir.md) e [Impressão - Ordens](03_Modulos/Impressao_Ordens.md).

### Transferências
Movimente produtos entre estabelecimentos e setores com controle de checkout/checkin. Veja [Transferências](03_Modulos/Transferencias_Movimentacao.md).

### Inventários
Faça contagem de estoque via leitura RFID. Consulte [Inventários](03_Modulos/Inventarios.md).

### Vendas
Registre vendas e pré-vendas por leitura RFID. Acesse [Vendas](03_Modulos/Vendas_Lista.md).

### Rastreabilidade
Acompanhe o histórico completo de cada etiqueta na [Linha do Tempo](03_Modulos/Linha_do_Tempo.md).

## Tipos de Usuário

O sistema possui quatro perfis de acesso:

| Perfil | Descrição |
|--------|-----------|
| **Administrador** | Acesso total ao sistema |
| **Operador** | Operações básicas (inventários, transferências, vendas) |
| **Vendedor** | Consulta de suas próprias vendas |
| **Fornecedor** | Criação e gestão de ordens de impressão |

Saiba mais em [Tipos de Usuário](03_Modulos/Tipos_Usuarios.md).
